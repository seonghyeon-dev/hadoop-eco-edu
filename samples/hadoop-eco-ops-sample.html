구성요소는 각각 한 가지 역할만 맡는다

구성요소역할비유비유와 다른 점
Airflow언제, 무엇을, 어떤 순서로 할지 지시한다작업 일정표를 든 작업반장상황을 보고 순서를 바꾸지 않는다. 데이터는 직접 만지지 않는다
YARN클러스터의 CPU · 메모리를 나눠 준다공용 작업장의 자리 배정 담당나눠 주는 것은 자리가 아니라 CPU · 메모리 묶음(container)이다
Spark큰 계산을 쪼개 여러 서버에서 동시에 처리한다계산팀 (driver = 팀장, executor = 팀원)팀원 수는 실행 전에 정해지고, 실행 중에 바뀌지 않는다
TezHive SQL을 실제 작업으로 바꿔 실행한다Hive SQL 주문서를 받는 또 다른 계산팀—
HDFS파일을 조각내 여러 서버에 복사본과 함께 보관한다여러 창고에 나눠 보관하는 창고 시스템파일 하나도 조각(block) 단위로 여러 창고에 흩어진다
Hive Metastore테이블이 어느 파일인지 목록을 관리한다도서관 목록 카드목록 카드는 Oracle DB에 저장된다
Iceberg파일 목록과 적재 이력을 메타데이터 파일로 관리한다새 서류만 덧붙이는 장부장부도 파일로 저장되고, 쌓이면 정리(유지보수)가 필요하다
